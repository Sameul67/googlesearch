# Citace a zdroje

## Zadání a technické zdroje

- Harvard University, CS50’s Web Programming with Python and JavaScript, Project 0: Search. Zadání, požadavky na stránky a parametry vyhledávacích formulářů: <https://cs50.harvard.edu/web/projects/0/search/> (přístup 22. 10. 2026).
- Google Search. Cílová adresa formulářů pro textové, obrázkové a pokročilé vyhledávání: <https://www.google.com/search> (přístup 22. 10. 2026).
- W3C Markup Validation Service: <https://validator.w3.org/>.
- W3C CSS Validation Service: <https://jigsaw.w3.org/css-validator/>.

## Použitý prompt a autorský podíl

- Prompt zadavatele (22. 10. 2026): „Vytvořte web dle zadání CS50 Harvard Web Projects 0: Search; přidejte další stránku s co největším množstvím formulářových prvků, na všech stránkách odkazy na validaci HTML a CSS a citace a zdroje, a do projektu Google Search odkaz na portfolio.“
- Herní vizuální motiv, HTML, CSS a JavaScript připravil AI asistent GitHub Copilot na základě promptu výše a následného požadavku: „udělej mi ten google do game tematiky a tu citaci ai udělej z githubu“.
- GitHub, **About GitHub Copilot**. Oficiální informace o GitHub Copilot jako AI asistentovi pro vývoj softwaru: <https://docs.github.com/en/copilot/get-started/about-github-copilot> (přístup 22. 10. 2026).
- Texty a rozvržení stránky Player Loadout jsou ukázkou vytvořenou pro tento projekt. Projekt nepoužívá převzaté obrázky ani externí grafické soubory.
